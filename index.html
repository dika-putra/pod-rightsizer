Pod Rightsizer

Unggah CSV CPU dan Memory dari Grafana. Hasilnya rekomendasi request dan limit, biaya sekarang, dan estimasi penghematan per bulan.

1. Ambil data dari Grafana

  1. Buka dashboard, atur time range yang mau dianalisis (misal 24 jam atau 14 hari).
  2. Arahkan mouse ke judul panel CPU Usage atau Memory Usage, klik menu titik tiga, pilih Inspect, lalu Data.
  3. Buka Data options. Di Show data frame pilih Series joined by time.
  4. Matikan Formatted data supaya angkanya murni, tanpa teks MiB atau milicore.
  5. Klik Download CSV. Ulangi untuk panel satunya kalau mau hitung CPU dan Memory sekaligus.

2. Unggah CSV

Boleh pilih beberapa file sekaligus: CPU, Memory, jumlah pod (Pod Available, Pod Desired), dan Monthly Cost. File dibaca di browser, tidak diunggah ke mana pun.
    Dipakai untuk menghitung harga CPU dan memory secara otomatis. Ambil dari panel Monthly Cost $, atau unggah CSV panel itu.
    Pengaturan

    Sidecar di pod (opsional)

    Angka di tool adalah total pod. Kalau pod punya container lain (misal nginx), isi request dan limit-nya supaya snippet resources hanya berisi bagian container utama.

    Harga untuk hitung biaya

    Satu angka biaya tidak cukup untuk dua harga, jadi harga Memory dihitung dari rasio terhadap harga CPU. Rasio 0.14 hanya contoh, ganti kalau kamu tahu rasio sebenarnya. Jumlah pod diisi otomatis dari rata-rata pod bersamaan di data.

    Ringkasan dan rekomendasi

    Snippet konfigurasi untuk disalin

    Format Helm values. Sesuaikan dengan chart kamu. Angka resources sudah dikurangi sidecar kalau kamu mengisinya di Pengaturan.
